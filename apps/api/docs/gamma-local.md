# 감마 전용 로컬 키·실제 LLM 검증

2026-11-03 사용자가 Google 결제 없이 감마 합성자료를 검증하도록 승인한 **테스트 한정 구성**이다. 운영의 외부 관리형 KMS 계약을 바꾸지 않는다. Google 로그인·결제·토큰이 필요하지 않으며 OpenAI 호출 비용은 별도로 발생한다.

## 분리와 접근 경계

- `src/test/java/com/payse/api/analysis/service/GammaLocal*`와 `GammaLiveTest`는 일반 서버 JAR에 들어가지 않는다. `aiArchiveCheck`가 혼입을 검사한다.
- 실행 구성은 명시 활성화와 키·LLM 설정·비용 정책·합성 원천 버전을 모두 요구한다. 서버 시드의 `initialCase=gamma-life`에 대응하는 유일한 사용자만 허용한다.
- 분석 controller 진입 전에 기존 DB 세션 인증과 감마 사용자, 현재 연간 원천 버전을 확인한다. 본문의 `userId`나 fixture의 `verified` 표식으로 권한을 부여하지 않는다. 일반 금융 API는 기존 동작을 유지한다.
- 감마 원천과 분류 정답은 분리한다. 입력은 실제 DB의 소유권·연결·원천과 다시 대조한다. 이체 금액·일시만으로 관계를 확정하지 않는다.
- `GammaLocalKeys`는 표준 AES-256-GCM으로 기억별 데이터 키를 감싼다. 기존 `EnvelopeCipher`가 본문과 사용자·기억 문맥을 암호화한다. 다른 사용자, 다른 기억, 다른 상위 키 및 변조는 실패한다.
- 키 파일은 명시한 절대 경로의 일반 32바이트 파일만 허용한다. 키가 없거나 잘못됐을 때 자동 교체하지 않는다. 키를 잃으면 해당 암호문을 복구할 수 없다. 동일 PC의 파일 기반 키는 관리형 KMS와 같은 격리·감사·복구 보장을 제공하지 않는다.

## 실제 호출 검증

저장소 루트에서 실행한다. 아래 인자는 사용자가 이미 승인해 저장한 키 파일과 실제 설치한 PostgreSQL 도구 경로를 지정한다. 실행 폴더는 존재하지 않는 새 경로여야 한다.

```text
python -B apps/api/testing/analysis/gamma_local.py --live --pg-bin <PostgreSQL-bin> --work-dir <새-검사-폴더> --env-file <저장소의-.env.local-절대경로>
```

실행기는 새 폐기용 PostgreSQL에 일반 금융 테이블과 감마 연간 1,825건을 적재한다. 비교용 알파·베타도 같은 일반 테이블에 준비한다. 기존 서버 주소나 운영 DB를 입력받지 않는다. 연결된 원천 상태에서 월급·이체 근거 부족·반복 지출의 세 표본을 HTTP 접수 → 허용 → 본문 제출 → 실제 OpenAI → 검증 → 암호화 저장 → 결과 조회 순서로 검사한다. 일반 대기 60초, 요청별 6,000/1,200 토큰, 20초 통신 제한을 유지한다. 실패한 모델 호출을 자동 재시도하지 않는다.

같은 테스트 API를 재시작하고 저장 결과를 복구하며 추가 모델 호출이 없는지 확인한다. 금융 원천·설정·버전을 전후 비교한다. 연간 전체 자료가 저장돼 있다는 검사와 세 표본의 실제 모델 검증을 구분하며, 이를 1,825건 전체의 정확도로 보고하지 않는다. 실제 휴대폰·운영 서버 배포는 별도다.

실제 호출 중 확인한 공통 문제도 수정했다. 공개 분류 기준은 한글을 그대로 쓰고 반복 필드명을 `columns`·`rows` 표로 표현해 입력을 줄인다. 테스트에서 표를 원래 JSON으로 복원해 모든 값·구조가 같음을 확인한다. 기준이나 정답을 제거하지 않고 6,000토큰 제한을 유지한다. 보존 지침은 `active`를 사용자 승인·장기 참고와 구분한다. 현재 유효한 후보·판단 유보는 활성으로 제안하고, 부적합 근거가 있으면 비활성 사유를 제안한다. 서버는 모델의 플래그를 덮어쓰지 않는다.

키와 실행 비용 장부는 Git 제외 `.harness/gamma-local-private/`에 두고 현재 실행 사용자와 시스템 계정으로 접근을 제한한다. OpenAI 키를 복제하지 않고 기존 `.env.local`을 명시 참조한다. DB 비밀번호는 새로 생성해 하위 프로세스 환경으로만 전달한다. 모델 입력·응답 원문·토큰·키는 실행 로그에 남기지 않는다. 입력 파일은 테스트 생성기로 만든 합성 사례이며 운영 요청 저장 기능이 아니다.

검사 폴더의 `result.json`, `live-summary.json`, `java-tests.log`에서 상태를 확인한다. 개별 실행 실패도 비용 장부에 남으며, 결과가 없는 예약을 임의로 지우고 재실행하지 않는다. 기본 `test`와 CI는 `GammaLiveTest`를 제외한다. 유료 검사는 별도 `gammaLiveTest`와 명시 승인 환경을 요구한다.

## 비용 해석

- 기본 모델은 이미 연결 검증한 `gpt-6-luna`, 추론 설정은 `none`이다. [모델 단가](https://developers.openai.com/api/docs/models/gpt-6-luna)와 [전체 요금표](https://developers.openai.com/api/docs/pricing)를 2026-11-03 확인했다.
- 이번 실행의 장부는 **실제 청구서가 아닌 보수적인 예산 평가**다. 입력은 캐시 쓰기를 포함해 100만 토큰당 USD 0.25, 출력은 USD 0.50, 환산은 USD당 3,000원을 사용한다. 환산값을 실제 환율이라고 표시하지 않는다. 계수 비용은 무료 여부를 확인하지 못해 1회 100원을 보수적으로 계상하며 실제 청구는 별도 대조한다.
- 사용자 확인상 온보딩 외 기존 API 사용은 없다. 온보딩 청구 미확정분은 100원을 예약해 둔다. 새 검증 실행은 1,000원을 먼저 예약하고, 실행 중에는 기존 PostgreSQL 비용 장부로 전송권·사용량을 기록한다. 다음 실행은 이전 집계와 미확정 예약을 포함한다. 누적 신규 차단선은 기존 45,000원을 유지한다.
- 로컬 키는 외부 유료 API를 호출하지 않으므로 명시 `kmsMicros=0`을 사용하며 KMS 비용 행을 만들지 않는다. 기존 Google KMS 운영 구성은 계속 양수 KMS 단가를 요구한다. 미설정 단가를 0으로 대체하지 않는다.

## 직접 실행과 제거

검증 후 별도 시험 DB에서 계속 사용할 때는 API 폴더의 `gammaLocalServer` Gradle 작업을 사용한다. 기존 DB·인증 설정 외에 아래 값을 **비공개 설정 파일**로 명시한다. 기본 접속은 loopback이며 외부 노출·운영 DB 연결은 별도 배포 작업이다.

```properties
payse.gamma-local.enabled=
payse.gamma-local.key-file=
payse.gamma-local.llm-file=
payse.gamma-local.project=
payse.gamma-local.pricing=
payse.gamma-local.source-version=
```

시험 종료 시 `GammaLocal*`, `GammaLiveTest`, `ApiTestConstants.GammaLocal`, `testing/analysis/gamma_local.py`, `test_gamma_local.py`, Gradle의 두 감마 실행 작업과 제외·혼입 검사, 이 문서 및 실행 문서의 링크를 제거한다. 일반 서버 JAR의 코드 경로나 공개 API에 감마 분기를 추가하지 않았다. 공통 프롬프트 압축·활성 의미 보완, 무료 키 비용을 표현하는 일반 가격 검증과 Google KMS의 양수 검사에는 감마 의존성이 없다.

로컬 상위 키는 연결된 시험 DB·백업·복구 필요성을 확인한 뒤 폐기한다. Google KMS로 나중에 전환하더라도 기존 로컬 암호문이 자동 변환되는 것은 아니다. 폐기 가능한 합성 결과는 제거 후 재생성하거나 별도로 검토한 키 이행 절차가 필요하다.
