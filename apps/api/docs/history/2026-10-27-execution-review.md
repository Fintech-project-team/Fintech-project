## 당시 검증 결과

각 EX-A~EX-W는 동일 항목(트리거·입력·순서 있는 조건·역할·호출 상한·출력 검증·상태/저장·실패·근거·인수 입력)을 포함한다. AI 하위 경로에만 G0~G7을 적용하며 금융 조회·쓰기·로컬 계산은 해당 동작의 조건표를 따른다. ‘필요 시/신뢰도가 높음/의미 있는 변화’만으로 실행 조건을 끝내지 않고 필드 변경·숫자 경계·정책 미설정 시 처리로 풀었다.

코드·호출부·기존 테스트 정의와 첨부 본문을 대조했고, 별도 검토에서 발견한 AI 게이트와 일반 저장의 혼동, replay 이전의 참조 검사, 명시 요청이 자동 분기에 가로막히는 조건, queued 작업 재평가 누락을 보완했다. 기능 테스트를 읽은 사실과 실제 실행을 구분한다. 이 문서의 확정 정책은 구현 완료 선언이 아니다.
