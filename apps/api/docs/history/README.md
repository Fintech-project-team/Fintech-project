## 기록 기준

- 날짜가 있는 작업 제목과 원래 문서 경로를 적는다. 기록 날짜와 실제 사건 날짜가 다르면 구분한다. 확인할 수 없는 사건 날짜는 추측하지 않는다.
- 특정 작업에서만 유효한 허용 범위, 수정·검토 결과, 설치·배포 안내, 과거 판단을 기록한다. 오래된 문장을 현재 명령이나 구현 완료 선언으로 읽지 않도록 당시 기록임을 표시한다.
- 계속 적용되는 정책, 현재 구현 여부, 미결정 사항, 데이터의 기준 시각, 테스트 조건, 필수 코드 주석 날짜는 현행 문서에 남긴다. 일회성 표현을 없애는 과정에서 이 조건을 삭제하거나 확정하지 않는다.
- 원문을 옮길 때 의미와 근거를 보존하고 상대 링크를 새 위치에 맞춘다. 기존 경로는 필요한 경우 현행 기준과 이력을 연결하는 짧은 안내로 남긴다.
- 일반적인 코드 변경 이력은 Git·Issue·PR에 남긴다. 모든 작업마다 새 이력 MD를 만들 필요는 없다. 독립적으로 보존할 문서 기록이 있을 때만 추가한다.
- 과거 문구와 현행 규칙이 다르면 현행 문서와 최신 합의를 기준으로 개발한다. 과거 기록을 근거로 정책을 되돌리지 않는다.
