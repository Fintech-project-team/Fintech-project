# 기관 기준정보

`kr-banks.json`은 국내 시중·지방·인터넷·특수은행의 검토된 기준정보다. 내부 code는 PAYSE 키이며 공급자 기관 코드가 아니다. 근거 URL·확인일·분류는 파일에 보존한다. 현행 범위 밖 금융기관을 포함했다고 표시하지 않는다.

`institutions.py`는 은행 기준정보와 합의된 네 카드사를 `institutions(code,kind,name)`에 적재할 행으로 만든다. `export_sql.py --out <새 파일>`은 INSERT SQL만 생성한다. 초기 기관 테이블에 한 번 적재하며 충돌을 무시하지 않는다.

기존 DB에는 `--synchronize-reviewed`를 명시해 별도 SQL을 생성한다. 기관 테이블을 잠근 트랜잭션에서 누락된 기준 행을 추가하고, 확인된 종전 네 은행명(국민·신한·하나·기업)만 현행 은행명으로 갱신한다. 코드의 종류·이름이 승인된 값과 다르면 전체 롤백한다. 사용자 계좌·동의·원천 거래를 생성하거나 수정하지 않으며 목록 밖 기관을 삭제하지 않는다. 이 SQL도 사람이 확인 후 별도로 실행한다.

금융 준비 도구는 이 기준정보의 code/name을 읽고 같은 키를 참조한다. 생성 묶음의 bank-directory.json은 재현용 복사본이며 수정 기준은 이 폴더다. 은행 목록 20개와 준비된 계좌 기관 5개를 구분한다. 기관 행 존재는 연결 동의·조회 API 지원·사용자의 보유 계좌를 뜻하지 않는다.
