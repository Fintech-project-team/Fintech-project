# Flutter 모바일 앱

목표 기술은 Flutter/Dart다. 현재는 이전 app/src 골격과 Node workspace 표시만 있고 pubspec·Dart 앱은 초기화되지 않았다.

초기화 담당자는 [전환 기준](../../docs/harness/FLUTTER_TRANSITION.md)에 따라 기존 변경을 보존하고 실제 앱 경로·역할 정책·Flutter 검사·계산과 API 계약을 함께 연결한다. app/src에 새 Expo 코드를 작성하지 않는다.

[스킬 안내](../../docs/harness/FLUTTER_SKILLS.md)는 작업 지침이며 앱이 실행된다는 뜻은 아니다.
