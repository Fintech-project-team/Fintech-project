# Flutter 모바일 앱

B가 UI·로컬 계산을 담당한다. 서버 더미 조회·계좌 선택·현재 금액·계획·반복 후보·복수 소비 시뮬레이션·조정은 버전별 기준을 따른다. 금액·소비 집계·반복 후보 수치는 순수 Dart 모듈에서 계산한다. 생성자 주입과 앱/세션/화면 수명을 구분한다. 확정 설정은 서버, 시뮬레이션 입력/결과는 메모리에 둔다. 현재 이전 app/src 골격의 존재는 Flutter 구현 완료가 아니다.

[현행 기준](../../docs/app-architecture.md). 상세 문서는 해당 담당 영역의 `docs/`에 두고 공통 계약을 복제하지 않는다.
