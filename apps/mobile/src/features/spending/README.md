# spending — 이전 골격

cashflow 역할의 이전 골격이다. 현재 화면은 쓸 수 있는 돈 홈·계산 내역·변경 미리보기다. 일/주 사용 현황·What-if·계좌별 부족을 추가하지 않는다. 계산은 실제 Dart 순수 계산 경계에서 공유한다.

[현재 MVP](../../../../../docs/mvp-scope.md)와 [Flutter 전환 기준](../../../../../docs/harness/FLUTTER_TRANSITION.md)을 따른다. 이 안내만으로 새 lib 경로가 허용되지는 않는다. 역할 정책·작업 명세를 초기화에서 함께 맞춘다.
