# 더미 원천 자료

data 역할. 사용자별 1년 계좌/카드 자료, 기준 시각·시드·기관/상품·응답 버전을 명시한다. 계정 수·구체 금액·생성 방식은 후속 더미 설계에서 정한다. CODEF는 참고 자료이며 더미는 PAYSE 공통 계약을 따른다. 실제 금융기관 응답과의 완전 일치를 주장하지 않는다. 취소·환불·중복·내부 이체·부분 정산·월말·부족 사례를 계약에 맞춰 검증한다.

[현행 기준](../../../docs/data-contracts.md). 상세 문서는 해당 담당 영역의 `docs/`에 두고 공통 계약을 복제하지 않는다.
