# 확장 경계

현행 범위는 [제품 기준](product-baseline.md), [계산](calculation-rules.md), [데이터 계약](data-contracts.md)이 우선한다.

- v1.0: 서버 준비 더미, 데모 사용자·세션, 사용자 설정 영속화, Flutter 로컬 계산, v0.7 LLM 연동, 계획·복수 소비 시뮬레이션·조정·수동 정정. 각 버전 P0/P1은 제품 기준을 따른다.
- 후속: 실제 금융 연동·실제 본인인증·실제 SMS·매월 추가 적립은 별도 확장이다. 더미 응답과 정규화 모델 사이 adapter 경계를 유지한다.
- 원천 계좌·카드·거래 값은 사용자가 바꾸지 않는다. 자동 지급 연결의 수동 정정은 PAYSE 내부 링크·계획·배정 변경이다.
- 서버는 저장 제약을 검증하지만 U·미래 잔액을 재계산하지 않는다. 로컬 계산 구현과 API/LLM adapter를 분리한다.
- 공통 문서는 `docs/`, 상세는 해당 앱·기능의 `docs/`에 두며 영향받는 두 담당자가 변경을 확인한다. 기존 Git·작업 명세·검사 정책은 유지한다.

폴더나 스킬의 존재만으로 새 기능·서버·테스트 체계의 구현 완료 또는 필수 도입을 선언하지 않는다. 상세 상품 계약과 구현 경로는 검증한 사실만 기록한다.
