# 현행 계약 안내

[데이터·API 기초 계약](data-contracts.md), [DB 최소 구조안](database-schema.md), [계산 규칙](calculation-rules.md)이 현행 기준이다. 기존 수동 잔액 덮어쓰기 명령을 신규 API 요구로 사용하지 않는다.

이는 완성된 OpenAPI·DDL이 아니다. 담당자는 [남은 설계 작업](open-decisions.md)에 따라 PAYSE 필드·오류·버전·멱등·제약을 검증한다. CODEF는 참고 자료이며 실제 공급자 응답 매핑은 후속 실연동 작업이다. 이 경로는 기존 검사·문서의 연결을 유지한다.
