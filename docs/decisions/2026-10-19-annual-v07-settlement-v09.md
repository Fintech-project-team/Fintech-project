- 날짜: 2026-10-19.
- 결정: 연간·월별 순소비 최소 결과를 v0.7, 자동 지급 연결 확인 필요 표시와 사용자 수동 정정을 v0.9에 구현한다. MVP 1.0 범위는 바뀌지 않는다.

## 이유

- 연간 소비는 반복 후보와 같은 1년 로컬 집계를 쓰고, v0.7 분류 수정 결과가 바로 반영된다.
- 정정은 v0.9의 확정 쓰기(버전·멱등·변경 기록)를 재사용하고, 계획과 실제가 다를 때 바로잡는 조정 단계와 성격이 같다.
- v1.0은 통합·QA·사용성 검증으로 유지해 11/2 동결을 지킨다.
