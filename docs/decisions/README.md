# 팀 결정 기록

작업별 파일에 날짜·결정·이유·영향·확인된 의사결정 주체를 적는다. 확인되지 않은 기여자 합의를 지어내지 않는다. integration은 개발 관련 기록을 정리한다.

현재 제품 기준은 [PAYSE 기준](../product-baseline.md)이며 [최신 대조 보고](../reconciliation-report.md)를 따른다. [2026-10-08 정정](2026-10-08-mvp-v03-alignment.md)은 과거 기록이다. 과거 결정 파일은 당시 상태·사건의 기록으로 보존하고 현재 Must를 정의하는 문서로 사용하지 않는다.
