# 데모 확인 기준

[제품 기준](../product-baseline.md)과 [화면 규칙](../v0.6-screen-rules.md)에 맞춰 서버 준비 더미와 합성 사용자로 확인한다. 데모 계정 수·금액·시나리오는 개발 중 정한다.

- 선택 계좌 합산·홈 금액과 계산 근거는 Flutter 결과다. 원천 금융 금액을 입력 화면에서 덮어쓰지 않는다.
- 자동 지급 연결과 수동 정정에서 중복 차감·보호 배정 복원·원천 불변을 확인한다.
- 서버 구현 후 앱 종료·재로그인 설정 유지, 다른 사용자 접근 차단, 기존 세션 유지·새 로그인 거절을 확인한다.
- 해당 버전에서 반복 후보·계획·복수 소비 시뮬레이션·조정의 확정 기준을 확인한다. 구현되지 않은 기능은 완료로 표시하지 않는다.

이 문서는 제품 동작 검증 기준이다. 합성 데이터는 PAYSE 공통 계약의 정상·누락·실패·중복/정정 사례로 검증한다. CODEF 응답 복제는 완료 조건이 아니다. 실제 공급자 호환은 후속 연동 검증이다. 사용성 검증은 현재 5~8명 목표를 유지하며 #40의 축소·생략은 미승인 변경안이다. 미실시를 검증 완료로 표시하지 않는다.
