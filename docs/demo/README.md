# 현재 MVP 시연 기록

실제 시연 담당자는 작업별로 배정하고 [MVP 범위](../mvp-scope.md)와 대조한다. 기존 allocation 역할이 전체 시연이나 아직 없는 배분 화면을 자동 담당한다는 뜻은 아니다.

수동 온보딩 → 모아둘 돈·예정 지출 → 홈·계산 내역 → 03-1 지급 처리 → 02-3 잔액 보정을 합성 사례로 확인한다. 예시 숫자와 두 동작의 차이는 [계산 규칙](../calculation-rules.md)을 사용한다. 저장 성공·실패·재조회와 실제 실행/미실행을 구분한다.

기준 시각·앱/API 버전·기기·기대/실제 결과·미검증을 기존 작업 기록에 남긴다. 제품 구현 전에는 시연 완료로 기록하지 않는다. 이후 LLM은 후보 생성·사용자 확인·기존 저장 반영을 별도 시연한다. Android 실제 기기 완료는 그 환경에서 확인한 뒤에만 표시한다.
