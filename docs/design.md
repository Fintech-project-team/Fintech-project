# PAYSE 공통 디자인 값

- 디자인 출처: 홈 02-1 `home-c-final.html`(C Minimal Spacious), 인증 컴포넌트 `auth-components.html`, 금융사 연결 12-1~01-2 `PAYSE 금융사 연결 시안`(2026-10-22 승인), 02-2 계산 내역·구성 바·홈 상태별·01-3·02-1a `PAYSE 계산 내역·첫 계산·코치마크 시안`(디자인 캔버스 v82, 2026-10-26 확정). 시안은 저장소 밖 탐색 자료이며, 작성·승인 경위는 [공통 문서 이력](../apps/api/docs/history/2026-10-22-common-doc-history.md)에 보존한다.
- 상위 기준: [v0.6 화면 규칙](v0.6-screen-rules.md), [화면 규칙 보완](../apps/mobile/docs/screen-rules-update.md), [계산 규칙](calculation-rules.md), [앱 구조](app-architecture.md). 화면 구성·문구·상태 의미는 상위 기준이 우선하며 이 문서는 시각 값만 정한다.
- 코드 단일 소스: `apps/mobile/lib/shared/design/` (`payse_tokens.dart`, `payse_theme.dart`). 이 문서와 코드가 다르면 코드를 기준으로 이 문서를 고친다.
- 이 문서에 없는 값은 확정이 아니다. 미정 항목은 아래 "미정" 절의 결정 기준을 따른다.
