# PAYSE 공통 디자인 값

- 디자인 출처: 홈 02-1 `home-c-final.html`(C Minimal Spacious), 인증 컴포넌트 `auth-components.html`, 금융사 연결 12-1~01-2 `PAYSE 금융사 연결 시안`(2026-10-22 승인). 세 시안은 저장소 밖 탐색 자료이며, 작성·승인 경위는 [공통 문서 이력](../apps/api/docs/history/2026-10-22-common-doc-history.md)에 보존한다.
- 상위 기준: [v0.6 화면 규칙](v0.6-screen-rules.md), [화면 규칙 보완](../apps/mobile/docs/screen-rules-update.md), [계산 규칙](calculation-rules.md), [앱 구조](app-architecture.md). 화면 구성·문구·상태 의미는 상위 기준이 우선하며 이 문서는 시각 값만 정한다.
- 코드 단일 소스: `apps/mobile/lib/shared/design/` (`payse_tokens.dart`, `payse_theme.dart`). 이 문서와 코드가 다르면 코드를 기준으로 이 문서를 고친다.
- 이 문서에 없는 값은 확정이 아니다. 미정 항목은 아래 "미정" 절의 결정 기준을 따른다.

### 금융 상태 색 (ThemeExtension `PayseFinanceColors`)

| 상태               | 값                                             | 표현                                                                   |
| ------------------ | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 음수 금액          | `#B42318`                                      | U+2212 `−` 기호 + 오류 색 + 호출자가 준 부족 문장. 0원으로 바꾸지 않음 |
| 정보 부족(값 없음) | `#62676F`                                      | 숫자 대신 "계산할 수 없어요" + 안내 문장. 0원 표시 금지                |
| 저장 실패          | 글자 `#B42318`, 바탕 `#FEF3F2`, 경계 `#FECDCA` | 오류 아이콘 + 문구 + 다시 시도                                         |
| 버전 충돌          | 글자 `#B54708`, 바탕 `#FFFAEB`, 경계 `#FEDF89` | 동기화 문제 아이콘 + 변경 확인 행동. 자동 재저장 없음                  |
| 경고(오류 아님)    | 글자 `#B54708`, 바탕 `#FFFAEB`, 경계 `#FEDF89` | 경고 아이콘 + 문구. 옐로로 경고를 표현하지 않음                        |
| 정보 안내          | 글자 `#175CD3`, 바탕 `#EFF8FF`                 | 토큰만 정의. 적용 화면(예: AI 해석 표시)은 미정                        |

저장 실패는 요청한 작업이 실제로 실패해 다시 해야 할 때, 경고는 실패는 없지만 선택의 결과나 부족한 진행 조건을 알릴 때 쓴다. 모든 상태는 색 + 아이콘/문구로 구분한다. base/surface 배경에서 본문 대비 4.5:1 이상을 유지한다. 실제 기기 화면 확인은 미완료다.

### 금액 구성 색·순서 (확정)

왼쪽부터 **모아둘 돈 `#555A61` → 예정 지출 `#9EA3AA` → 쓸 수 있는 돈 `#F4CF65`**. 쓸 수 있는 돈이 오른쪽 끝에 남는다. 장부 항목명 뒤 색 칩도 같은 색을 쓴다. 구성 막대 자체는 미정이다(§6).
