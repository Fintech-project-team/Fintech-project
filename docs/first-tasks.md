# 지금 시작할 작업

휴대폰 연결을 선행 조건으로 두지 않는다. 공통 구조가 develop에 통합된 뒤 아래 순서로 시작한다.

1. integration: Expo/서버 초기화와 공통 의존성·실행 명령을 한 PR로 준비한다. 기존 제안 버전의 호환성을 재확인한다.
2. integration + 세 담당자: API 계약·금융 정책 초안을 합의한다. 계약/fixture/대표 기대 결과부터 고정한다.
3. data: 합성 fixture와 PC에서 실행하는 mock-bank→api 경로를 구현한다.
4. cashflow: 연결·후보 확인·사용 여유·What-if 화면을 공개 계약에 맞춰 구현한다.
5. allocation: 배분 화면과 부족·링크 실패 상태, 공통 시연 시나리오를 구현한다.
6. integration: 라우팅·공통 클라이언트·계산 엔진을 연결한다. 계약 소비자 검사와 시나리오 통합을 수행한다.
7. 그다음 DB 영속화·모델 어댑터·Android 실기기 검증을 진행한다.

동시 개발은 공통 계약 이후 시작한다. UI 작업자는 임시 응답을 별도로 정의하지 않고 승인된 fixture/계약으로 개발한다. 기능당 하나의 task 명세와 작은 PR을 사용한다.
