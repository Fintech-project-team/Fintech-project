# 첫 개발 작업

개발 관리자 포함 3명의 기여자가 아래 순서로 진행한다. 휴대폰 연결은 뒤로 미룬다.

1. integration: [Flutter 전환 기준](harness/FLUTTER_TRANSITION.md)에 따라 앱·서버를 초기화한다. SDK, 역할 경로, Dart 검사, 계약·계산 패키지 연결을 함께 준비한다.
2. 3명 공동: API 데이터 형식과 금융 정책을 검토하고, 테스트용 합성 데이터와 기대 결과를 합의한다.
3. data: 합성 데이터를 만드는 mock-bank와 이를 조회하는 api를 PC에서 실행한다.
4. cashflow: 연결·지출 후보 확인·사용 여유·What-if 화면을 공통 데이터 형식에 맞춰 구현한다.
5. allocation: 배분 화면, 금액 부족·은행 링크 실패 처리, 시연 순서를 구현한다.
6. integration: 화면 이동·공통 API 클라이언트·계산 코드를 연결하고 각 기능이 함께 동작하는지 검사한다.
7. 팀: DB 저장·AI 교체 기능을 연결한 뒤 Android 빌드와 실제 기기를 검증한다.

위 이름은 작업 역할이다. 3명의 기능별 고정 배정은 아직 확정하지 않았으며, docs/ownership.md에 따라 작업별 담당자와 겸임 범위를 기록한다.
공통 데이터 형식을 합의한 뒤 동시 개발한다. 화면 담당자는 합의한 합성 데이터를 사용하고 임시 응답 형식을 따로 만들지 않는다.
기능마다 작업 명세와 작은 PR을 만든다. 각자 작업 폴더와 수정 범위를 분리한다.
